# FoodPlan AI 🇷🇺

Бесплатный Android-конструктор питания для России: пользовательская анкета → 25 вкусовых оценок → недельное меню → рецепты с граммовками и *оценочным* КБЖУ → продуктовая корзина.

## Текущий статус (20 октября 2026)

**Это рабочий инженерный прототип, НЕ готовый продукт и НЕ проверенный персональный диетологический план. Промежуточные debug APK не считаются релизом.**

- M0: архитектура и контракты в `docs/`.
- M1: Android-анкета и локальное DataStore-хранилище, параметры кухни, три степени усилий, российские магазины.
- M2: интерактивный опрос из 25 блюд и движок вкусового ранжирования. В каталоге 200 **комбинаторных шаблонов**, пока без независимой проверки нутриентов. Требование 150 настоящих проверенных рецептов НЕ закрыто.
- M3: прототип генератора на 7 дней с КБЖУ, количеством порций, фильтрами диеты/аллергенов/нелюбимых продуктов/времени/оборудования. Показатели примерные и не медицинское назначение.
- M4: единая продуктовая корзина на неделю, упаковки, домашние остатки, ручные цены в рублях с привязкой к городу и конкретному магазину. Актуальных цен российских сетей через API **ещё нет**.
- M5: просмотр шагов рецепта и замена блюда с пересчётом меню и корзины.
- M6: тесты JVM и Android эмулятора в CI; независимая продуктовая и нутриционная приёмка, полноценный release APK **ещё не выполнены**.

Сначала требуется довести M2–M6 до [критериев выпуска](docs/qa/RELEASE_GATE.md), а уже затем выпускать APK пользователю.

## Запуск разработки

`android/` содержит Kotlin/Jetpack Compose проект и независимый `domain` модуль.

CI: [GitHub Actions](../../actions). Сборка и тесты `android-ci.yml` автоматически запускаются после коммитов в main.

Документы: [ТЗ](docs/PRD.md) · [архитектура](docs/ARCHITECTURE.md) · [цены РФ](docs/DATA_AND_PRICING.md) · [тестовый маршрут](docs/qa/END_TO_END.md) · [Gauntlet](docs/qa/STATUS.md).

Персональные данные хранятся локально. Нет обязательного платного API, регистрации или подписки. Калькуляции предварительные, пока не верифицированы сведения о составе и актуальной стоимости товаров.
