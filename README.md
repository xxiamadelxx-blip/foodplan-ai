**Уточнение от 22.10.2026:** вкусовой опрос должен показывать
**фотографии/иллюстрации 25 блюд**, преимущественно знакомой домашней еды.
Том-ям, рамен и паста с креветками не нужны как обязательная база опроса.
В покупках на первом месте пачки/штуки, а не технические граммы и названия
«съедобная часть яйца». Пользователь подтвердил сохранение списка после
обычного закрытия и открытия. **Эти новые UX-улучшения пока записаны в backlog,
но не реализованы**, если отдельный кодовый Gauntlet не показал PASS.

**Статусы рабочей ветки и релиза различаются:** [PR #3](https://github.com/xxiamadelxx-blip/foodplan-ai/pull/3)
содержит код и инженерные проверки, которые могут отсутствовать в `main`.
Новые пострелизные решения не меняют дорожную карту M0→M6.

Бесплатное Android-приложение для России. **Цель:** персональный рацион на семь дней и собственный список продуктов с ценами выбранного магазина, отзывами и ограничением по бюджету.

**Корзина только в FoodPlan AI.** Никакого переноса в корзину магазина, оформления или оплаты заказа.

## Состояние на 20 октября 2026
- M0–M1: репозиторий, анкета, локальное сохранение, тесты.
- M2: 25 оценок блюд; **200 комбинаторных шаблонов + 76 отдельно составленных черновых рецептов**. Импортёры двух наборов USDA FoodData Central с независимой сверкой оригинальных архивов, точные источники КБЖУ для 37 из 37 ингредиентов (36 USDA, 1 российский производитель) и реестр состояний массы 37 ингредиентов (сырое/сухое/без рассола/упакованное). Подтверждено независимо **0 из требуемых 150**: этап ещё не принят.
- M3: семь дней, предварительные граммовки/КБЖУ, добавлен черновой подбор безопасных замен с ограничением по бюджету.
- M4: список на неделю, запасы, полный учёт фасовки и цен, экспериментальное чтение Магнита, подбор вариантов по цене и реальным отзывам, статус доступности по адресу. Другие магазины пока не подключены.
- M5: замены блюд и пересчёт списка.
- M6: неполная приёмка и тестирование. **Финальная APK ещё не готова.**

Бюджет выбирается непрерывным ползунком **100–100 000 ₽** с точным вводом любого целого рубля, включая **356 ₽ и 63 218 ₽**. При невозможности собрать полноценную неделю приложение показывает отдельно частичный, строго ограниченный известными ценами список продуктов с предварительным КБЖУ и предупреждением о дефиците. Оно не называет такой набор сбалансированным рационом.

Бюджет 2 500 ₽ запрещает заведомо неподъёмную корзину, 25 000 ₽ расширяет выбор продуктов/возможности разнообразия, но деньги не тратятся искусственно. Оценка товара без подтверждённых отзывов не придумывается, а при отсутствии цен соответствие бюджету не подтверждается.

См. [дорожную карту](docs/ROADMAP.md), [критерии выпуска](docs/qa/RELEASE_GATE.md), [Gauntlet](docs/qa/BUDGET_GAUNTLET.md) и [источники данных](docs/DATA_AND_PRICING.md).

Код: Kotlin, Jetpack Compose, offline-first DataStore, детерминированное доменное ядро, GitHub Actions. Никаких обязательных платных AI-API.
