# FoodPlan AI 🇷🇺

Бесплатный Android-конструктор недельного питания для России: анкета → предпочтения → рацион на 7 дней → рецепты с КБЖУ → продуктовая корзина для российских магазинов.

## Статус
- M0: архитектура, контракты, схема данных, ограничения, тестовые сценарии.
- M1: анкета Android и сохранение профиля на устройстве. **Разработка / тестирование.**
- M2–M6: пищевой портрет, рецепты, планировщик, корзина, приёмка и APK.

**Принцип безопасности:** наличие рецепта или оценочной цены не доказывает отсутствие аллергенов или соблюдение бюджета. Аллергены блокируются, неизвестная рецептура не признаётся безопасной, цена с непроверенным источником не помечается подтверждённой.

## Технологии
Kotlin · Jetpack Compose · Android 8+ · локальное хранение · Gradle / GitHub Actions. Без подписок, обязательной регистрации и платных API.
