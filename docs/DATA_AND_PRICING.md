# Россия: ассортимент, магазины и происхождение цен

## Магазины
Начальные варианты селектора: Пятёрочка, Магнит, Лента, Перекрёсток, Дикси, О’КЕЙ, ВкусВилл, Ашан, Самокат, Яндекс Лавка, Ozon fresh, Другой. Это варианты выбора, а НЕ готовые интеграции с их каталогами.

## Источники питания
1. Российская маркировка производителя, проверенная ручная нормализация и явные ссылки на происхождение.
2. Открытые нутриентные источники (USDA FoodData Central и Open Food Facts) как дополнительные, если условия использования допускают.
3. Нет автоматической подмены российских брендов чужими пищевыми аналогами без предупреждения.

## Источники цен
Только разрешённые публичные интерфейсы, официальные каталоги с допустимым доступом, легально полученные открытые наборы или введённая пользователем цена по чеку. Не предполагать, что существует публичное API каждой сети. Не обходить авторизацию/защиты и ограничения магазинов.
Каждое предложение содержит: источник, время наблюдения, регион, конкретный магазин, SKU/пакет, массу или единицу упаковки, цену в копейках, статус CONFIRMED / ESTIMATED / STALE / UNKNOWN. Иная цена в регионе запрещена для «подтверждённой» корзины.

## Расчёт
- Суммировать ингредиент из всех 7 дней по одинаковому идентификатору.
- Вычитать домашний остаток один раз, не допускать отрицательной закупки.
- Оптимизация закупки по размерам УПАКОВОК, а не пропорциональным граммам.
- Учитывать многомагазинность (M4), физическое наличие/срок годности при доступных данных.
- Неподтверждённая цена → budgetVerified=false, fitsBudget=null.
- Недоступный товар → список пробелов, не утверждать 100% покрытие.
- Показывать итог и разницу от недельного бюджета только после проверки всей корзины.

## Лицензии
Open Food Facts — учитывать ODbL, условия атрибуции и share-alike для производной базы. USDA FoodData Central — проверять актуальные условия/CC0 перед импортом. Не складывать несовместимые источники без разграничения provenance.

## Проверка открытых источников (20.10.2026)

- Росстат публикует еженедельные и городские/региональные **средние потребительские цены**: https://rosstat.gov.ru/statistics/price. Допустимо применять как статистический справочник ориентировочной стоимости категории, но **не как предложение конкретной Пятёрочки/Магнита** и не как проверку наличия.
- Магнит открыто показывает каталог на https://promo.magnit.ru/, однако показанный для посетителя товар и цена могут зависеть от города, магазина, подписки и акций. Нужен разрешённый стабильный доступ к ассортименту и условия использования для автоматической интеграции.
- Репозиторий https://github.com/magnit-tech/market-partner-api описывает **партнёрское API Магнит Маркет** с ключом X-Api-Key. Это не публичный анонимный API местных продуктовых магазинов, не использовать как бесплатную основу потребительских цен.
- Партнёрская страница X5 https://www.x5.ru/ru/partners/ не подтверждает наличие открытого API актуальных потребительских цен магазинов Пятёрочка.

Следствие: пока не подтверждён разрешённый структурированный канал от конкретной сети, в работающем приложении лишь ручные оценки с привязкой к городу/магазину и честным `verifiedShopPrices=false`. Автоматическое заявление «корзина точно дешевле недельного бюджета» недопустимо.
