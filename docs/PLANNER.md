# Планировщик недели (спецификация M3)

1. Собрать и проверить профиль, отметить невалидные данные (например, бюджет < 0, нереальная масса).
2. Удалить несовместимые по диете и строго запрещённым продуктам рецепты; неизвестный состав исключить.
3. Для совершеннолетних определить индивидуальную оценку энергопотребности по проверенной формуле и активностям; это оценка, а не медицинский диагноз. «Суперсушка» не допускает небезопасных целей; у детей/особых групп не рассчитывать автономно похудение.
4. Сформировать варианты распределения приёмов пищи, порций и нутриентов по дням.
5. Выбрать комбинацию с учётом: пищевых голосов, разнообразия, ограничения времени, остатков и общего недельного бюджета.
6. Свести одинаковые ингредиенты, вычесть запасы, решить задачу выбора упаковок и магазинов. Не заявлять оптимальность при неполном покрытии цен.
7. Если ограничения несовместимы: вернуть explainable UNSAT (какие именно ограничения мешают), не придумывать результат.
8. При замене блюда заново пересчитать ОБЩУЮ недельную корзину и сумму КБЖУ; давать варианты с минимальным изменением стоимости.
9. При любой небезопасной композиции, аллергене, плохих данных или недостоверной цене отказывать в статусе «проверено».

Целевая функция: сначала hard constraints (аллергия, допустимая диета, безопасность, состав) → затем обеспеченность питанием → бюджет при подтверждённых ценах → вкусы/разнообразие → удобство приготовления.
