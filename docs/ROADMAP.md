# FoodPlan AI: ориентиром является настоящая магазинная корзина

**Сквозная цель:** анкета → 25 вкусов → недельное меню → реальные SKU/фасовки выбранного российского магазина → автоматическая сборка магазинной корзины → пользователь проверяет цену и оформляет заказ.

M0: репозиторий, архитектура, проверяемые ограничения, CI.
M1: автономная анкета с сохранением, город/магазин, аллергии, техника, три степени усилий.
M2: не менее 150 **независимо проверенных** рецептов с происхождением нутриентов.
M3: безопасный подбор и оптимизация рациона по предпочтениям/диете/бюджету, меню 7×N.
M4: реальное получение товаров и цен, город/магазин/адрес, подбор SKU, упаковки и запасы; **заполнить реальную корзину магазина и проверить фактические количества**. Адаптеры сетей обособлены. Эксперимент Магнита в разработке, другие сети не завершены.
M5: замены блюд с пересчётом и обновлением корзины магазина, UX и сохранённые планы.
M6: независимый Gauntlet: реальный заказ без оплаты, повторяемые доказательства, отказ при блокировке/недоступности, эмулятор/физическое устройство, релиз APK.

Не путать: текстовый список покупок ≠ покупательская корзина магазина; клик ≠ подтверждённое добавление; открытая карточка товара ≠ актуальность цены в корзине.
