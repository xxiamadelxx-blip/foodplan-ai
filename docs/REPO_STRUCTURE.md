# Структура
android/app — Android Compose UI, в M1 профиль/DataStore; в M2+ Room catalogue.
android/domain — pure Kotlin, расчёт корзины, безопасность, тесты.
docs — ТЗ, архитектура, правила данных, роадмап, QA/доказательства.
.github/workflows — бесплатная облачная сборка, JVM и Android emulator.
contracts — JSON Schema для внешнего обмена.
fixtures — только синтетические тестовые записи, не настоящие цены.
