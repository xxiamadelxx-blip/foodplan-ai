# M4 · Публичные цены: пакетная проверка с защитой от отказа источника

**Дата:** 2026-10-23. **Тип:** независимая инженерная приёмка, **не** подтверждение полной недельной цены, кассовой стоимости или маркировки аллергенов.

## Исходный дефект

[CI #39965192109](https://github.com/xxiamadelxx-blip/foodplan-ai/actions/runs/39965192109) и [#39966557853](https://github.com/xxiamadelxx-blip/foodplan-ai/actions/runs/39966557853) показывали HTTPError/NOT_VERIFIED для множества SKU при блокировке сайта. Старый цикл запускал отдельный скрипт на 33 товара: для каждого снова обращался к `robots.txt` и пытался открыть карточку, даже когда весь источник не был доступен. Это нагрузка, не новая информация.

## Исправление в PR #3

- [a837442](https://github.com/xxiamadelxx-blip/foodplan-ai/commit/a837442dfcb692f9c5d08bb8089e98792b52383e): `tools/m4_chain_price_batch.py` переиспользует результат **одного** разрешённого GET `robots.txt`, делает обычные GET к опубликованным SKU без редиректов, без скрытых API или обхода блокировки.
- При HTTP 401/403/429 не обращается к следующим SKU. Для каждого запроса сохраняет структурированный `NOT_VERIFIED` JSON с причиной отказа и **без цены**. Частный HTTP 404 не блокирует другие разрешённые товары. Нет кэширования цены через неизвестный интервал, нулевой цены или подмены SKU.
- [d6eeb2b](https://github.com/xxiamadelxx-blip/foodplan-ai/commit/d6eeb2b944a5ff0aebe7958403ca4659ce536216): шесть независимых unit-тестов политики robots, 403, 429, 404, совместного чтения, запрета недостоверной стоимости.
- [c1b95e7](https://github.com/xxiamadelxx-blip/foodplan-ai/commit/c1b95e777be3106aa986b387f18610898ed55c7b): GitHub Actions теперь запускает пакетную проверку вместо 33 отдельных процессов. Если источник недоступен, отдельная пилотная оценка не скрывает выгрузку полного Kotlin-списка, но финальный source acceptance gate всё равно **FAIL** до появления подлинных цен.

**Не принимать** таблицу плотности *сырого* масла из Codex за удостоверение массы конкретной очищенной бутылки; массу категории C1 по ГОСТ нельзя выдавать за съедобную массу одного яйца. Общие физические справочники могут стать исходными материалами исследования интервала, но не прямой сертификат двух SKU.
