# M2: 25 оценок и фильтр кандидатов

## Что работает
- 25 уникальных вопросов о блюдах с оценками LIKE/OK/DISLIKE/NEVER_TRIED. Оценка не является утверждением о пищевой безопасности блюда.
- DataStore хранит ответы; повторная оценка заменяет прошлую.
- Проекция оценок в веса вкусовых тегов: +3/+1/-3/0.
- Ранжирование детерминировано, поддерживает штраф за повторы и сложность.
- Жёсткий отказ кандидату при неполных данных состава, известных аллергенах из введённого списка, несовместимой диете, исключённом ингредиенте, превышении времени, отсутствии техники.
- Детерминированный порядок при равных оценках по ID рецепта.
- Написаны JVM-тесты на 25 карт, ранжирование и перечисленные исключения.

## Чего этот результат НЕ доказывает
- Нет 150+ полноценных рецептов, подтверждённых КБЖУ и граммовок.
- Нет отнормализованного аллергенного словаря или привязки к упаковочной маркировке. Сопоставление free-text по точным словам не безопасно для клинических рекомендаций и **не должно считаться разрешением для аллергика**.
- Нет реальных данных о ценах российских магазинов и расчёта полной недели.
- UI-сортировка по реальному каталогу подключается только после каталога и источников.
- Нельзя рекламировать как работающий конструктор рациона и отправлять пользователю APK ради промежуточного milestone.

M2 принимается только после наполнения проверенными рецептами, реального использования оценок при отборе и тестов во взаимодействии с генератором недели.
