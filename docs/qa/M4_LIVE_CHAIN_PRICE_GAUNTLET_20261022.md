# FoodPlan M4 · независимая проверка приблизительных цен сети
Дата: 22 октября 2026 года

## Утверждённый контракт пользователя
Без адреса, остатков конкретного филиала, заказа, логина магазина и
платного API. Из публичного каталога российской сети нужны примерная
цена, название, фасовка, дата получения. Пользователь видит недельный
список продуктов, рецепты и настройки, не видит внутренний аудитор.

[GitHub Actions #13: настоящие HTTP-ответы, robots.txt, два SKU и

- **Крупа Мистраль Гречневая ядрица 900 г** · Магнит ·
  https://magnit.ru/product/1342500014-grechka_yadritsa_mistral_900g
  · **129,99 ₽ (12 999 коп.)**

Инструмент: `tools/m4_live_chain_price_probe.py`.
Разрешения robots проверяются до обращения к товарной странице.
Переадресации в другой SKU запрещены. Цена находится только рядом
с проверенным H1 и массой; перечёркнутые и рекомендованные товары
не считаются основной ценой. Код результата не содержит адреса.

Артефакт `m4-chain-price-public-evidence`: JSON-наблюдения,
временные метки UTC, SHA-256 видимого исходного HTML, код состояния и
цена. Результат источников **PASS**, тесты отрицательных сценариев 7/7.

## Реальная маленькая корзина: PASS (НЕ полный рацион)
В том же CI независимый `tools/m4_live_pilot_basket.py` загрузил
два JSON-наблюдения реальных цен и рассчитал **только эти две позиции**:
- 900 г риса: 2 пакета по 800 г × 49,99 ₽ = 99,98 ₽.
- 850 г гречки: 1 пакет 900 г × 129,99 ₽ = 129,99 ₽.
- **229,97 ₽ за два продукта**.

100 ₽ недостаточно; 356 ₽, 63 218 ₽, 100 000 ₽ достаточно **для этих
двух продуктов**, не для семидневного рациона. Тесты арифметики,
отсутствующих/устаревших цен и неподтверждённых источников: **5/5 PASS**.

## Android: PASS
[GitHub Actions Android CI #460](https://github.com/xxiamadelxx-blip/foodplan-ai/actions/runs/39773381825)
- Kotlin/JVM, debug APK: **PASS**.
- Android API 35 эмулятор: **43 инструментальных теста, 0 skipped, 0 failed**.
- Реальный Android WebView тестирует цену внутри конкретной отображаемой
  карточки, исключает зачёркнутый ценник и невидимый товар.
- Каталожный адаптер использует подтверждённые категории Магнита:
  рис, курица, гречка, макароны, овощи и фрукты. Общее содержимое
  овощного раздела повторно используется для нескольких ингредиентов.
- Сохранение цен остаётся предварительным; ни один числовой расчёт
  не утверждает, что товар безопасен при аллергии или имеет точные КБЖУ.

## Ограничения и следующий критерий
- **FAIL / NOT PROVEN: полный недельный список покупок на конкретном
  сформированном меню**. Есть подтверждённые реальные цены для двух
  независимых SKU, а не всех необходимых продуктов конкретной недели.
- Неизвестная цена никогда не заменяется нулём, а неполный список не
  считается уложившимся в недельный бюджет.
- Актуальные цены могут отличаться в филиалах и меняться, поэтому
  каждая отображаемая цена называется ориентировочной.
- Никакая адресная или кассовая проверка не нужна для приёмки M4.
- Верификация 150 рецептов M2 остаётся самостоятельной задачей.
