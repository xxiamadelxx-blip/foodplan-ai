## Авторитетный источник состава
USDA FoodData Central, Foundation Foods April 2026:
https://fdc.nal.usda.gov/download-datasets/

Данные доступны в CSV и JSON. Скрипт `tools/fdc_candidates.py` принимает оригинальный CSV ZIP, ищет кандидатов по англоязычному названию и формирует файл с FDC ID, нутриентами на 100 г, датированным источником и меткой `CANDIDATE_NOT_VERIFIED`.

Пример использования из облачного Codespace (без ПК):

```bash
python tools/fdc_candidates.py FoodData_Central_foundation_food_csv_2026-04-30.zip \
  --contains "Egg" --output /tmp/egg-candidates.json
```

**Ограничение:** программа НЕ меняет Kotlin-базу и НЕ помечает ингредиент проверенным. Требуется независимая проверка того, что выбранный FDC ID относится к правильному виду, сырому/готовому состоянию, пищевой части и к местному аналогу, плюс проверка аллергенов по российской маркировке. Импорт FDC не заменяет технологическую экспертизу рецепта. Яйца/молоко/соя могут сопровождаться следами аллергенов в конкретном товаре; источники различать.

Open Food Facts также доступен, но его пользовательские данные не гарантируют полноты и достоверности и имеют ограничения по лицензии ODbL. Не смешивать наборы данных автоматически и не считать отзывы о магазине доказательством пищевой безопасности.

## Фактическая проверка из архива USDA 2026-04-30

Запуск [GitHub Actions #39458032749](https://github.com/xxiamadelxx-blip/foodplan-ai/actions/runs/39458032749) успешно скачал USDA Foundation Foods CSV и сохранил пять файлов кандидатных записей (Rice, Chicken, Egg, Tomato, Mushroom) как артефакт `m2-usda-food-candidates-unverified`. Первую попытку пришлось исправить: `rice` по подстроке находил `PRICE`, а первые записи иногда не содержали нутриентов. Исправленный инструмент принимает только совпадение самостоятельного слова и полные значения энергии/белков/жиров/углеводов.

**Пока внесены два значения базового сырья с FDC ID:**
- `rice` (белый длиннозёрный рис, сырой/сухой): FDC [2512381](https://fdc.nal.usda.gov/food-details/2512381/nutrients), энергия 358.705 ккал, Б 7.03885 г, Ж 1.033 г, У 80.31315 г на 100 г.
- `chicken` (куриная грудка без кожи и костей, сырая): FDC [2646170](https://fdc.nal.usda.gov/food-details/2646170/nutrients), энергия 106.034 ккал, Б 22.525 г, Ж 1.934 г, У 0 г на 100 г.

Это **сопоставление стандартных продуктов**, не подтверждение конкретной торговой марки российского магазина. Аллергенный состав и возможные следы не верифицированы, у остальных ингредиентов значения остаются предварительными. Даже рецепты с этими двумя ингредиентами **не прошли M2**: `RecipeEvidenceAudit` продолжает возвращать 0 подтверждённых рецептов.


## 20.10.2026: уточнение основы массы ингредиентов
Реестр `IngredientWeightBasisRegistry` фиксирует для всех 37 ингредиентов смысл граммовки: сухая крупа/мука/паста; сырое мясо и овощи; замороженные ягоды; готовый нут **без рассола**; упаковочные молочные продукты. Значения в составе рецептов и недельной продуктовой корзине относятся к этому состоянию, а не к готовому весу на тарелке. Реестр является инженерной нормализацией, **не внешним доказательством источника КБЖУ и не рассчитанным выходом готового блюда**.

Текущий каталог: **200 тестовых шаблонов + 76 отдельно составленных черновиков = 276 записей; 0 из 150 независимо проверенных**. Имеется самостоятельный набор `CuratedRecipeBatch2` из 16 блюд и тесты ингредиентов/оборудования/аллергенов. Результат Android CI см. `docs/qa/STATUS.md`.
