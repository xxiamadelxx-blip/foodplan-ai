## Авторитетный источник состава
USDA FoodData Central, Foundation Foods April 2026:
https://fdc.nal.usda.gov/download-datasets/

Данные доступны в CSV и JSON. Скрипт `tools/fdc_candidates.py` принимает оригинальный CSV ZIP, ищет кандидатов по англоязычному названию и формирует файл с FDC ID, нутриентами на 100 г, датированным источником и меткой `CANDIDATE_NOT_VERIFIED`.

Пример использования из облачного Codespace (без ПК):

```bash
python tools/fdc_candidates.py FoodData_Central_foundation_food_csv_2026-04-30.zip \
  --contains "Egg" --output /tmp/egg-candidates.json
```

**Ограничение:** программа НЕ меняет Kotlin-базу и НЕ помечает ингредиент проверенным. Требуется независимая проверка того, что выбранный FDC ID относится к правильному виду, сырому/готовому состоянию, пищевой части и к местному аналогу, плюс проверка аллергенов по российской маркировке. Импорт FDC не заменяет технологическую экспертизу рецепта. Яйца/молоко/соя могут сопровождаться следами аллергенов в конкретном товаре; источники различать.

Open Food Facts также доступен, но его пользовательские данные не гарантируют полноты и достоверности и имеют ограничения по лицензии ODbL. Не смешивать наборы данных автоматически и не считать отзывы о магазине доказательством пищевой безопасности.
