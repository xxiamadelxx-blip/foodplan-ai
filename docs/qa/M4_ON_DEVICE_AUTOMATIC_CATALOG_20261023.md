# FoodPlan · M4 встроенный автоматический парсер цен · 23.10.2026

## Прямое требование пользователя

Не искать и собирать каждую корзину руками через помощника или GitHub Actions.
После выбора сети, бюджета и недельного меню **сам APK** получает цены
по публичным ранее найденным путям, подбирает реальные целые упаковки,
показывает неизвестное честно. Пользователь видит только три раздела.
В регулярном алгоритме **нет ИИ, облачного платного API и чекаута**.

## Реализованная Android-механика, рабочий PR #3

- `FoodPlanHomeScreen` на вкладке **«Продукты»** автоматически включает
  `MagnitAutomaticPriceUpdater` для магазина `Магнит`, если есть
  непустой реальный список. Пользователь не открывает технический WebView
  и не нажимает отдельную кнопку для каждого товара. При смене состава
  недели меняется ключ сканирования; есть ограничение **3 независимых
  составов недели за один сеанс**, чтобы не запускать бесконечные обходы.
- `MagnitKnownProductPaths`: **35 известных публичных адресов SKU**
  (в том числе 4 позиции с несовпадающей физической и съедобной единицей).
  Это **адреса входа в каталог, не цены**.
- `MagnitAutomaticPriceAdapter`: обычный Android HTTPS GET
  `robots.txt`, разбор разрешений и задержки, только официальный
  `magnit.ru/product/...`, без редиректов, скрытых API, обхода блокировок
  и передач личного профиля. Считывает именно HTML магазина; при HTTP
  401/403/429 останавливает дальнейшее чтение.
- `MagnitPublicHtmlPriceParser`: проверяет саму карточку,
  видимое название, массу или физические штуки/объём и точную видимую
  цену; исключает скрытые/старые/рекомендованные цены.
- `AutomaticRetailScanPolicy.verifiedMassOffers`: сохраняет только
  сопоставленные актуальные SKU с доказанной граммовой фасовкой через
  `ProfileStore.saveRetailerOffer` и Android DataStore. Пересчитывает
  `RetailerBasketPricing.estimate` для выбранной недели.
  Этим результатом может воспользоваться детерминированный рефайнер
  плана; без доказанных цен не подменяет стоимость выдумкой.
- `RetailWeekQuoter`: сохраняет отдельную видимую цену коробки/бутылки/
  килограмма с кожурой/банки с заливкой, **но не выводит выдуманное
  количество** из нутриентных граммов. Четыре неоднозначные единицы:
  `banana`, `chickpeas`, `egg`, `oil`.
- Сайт или интернет могут быть недоступны: исходное меню, рецепты,
  расчёт нужных продуктов и сохранение работают автономно,
  стоимость отмечается UNKNOWN. Публичная цена никогда не означает
  физически проверенный состав/аллергены или наличие.
- Другие сети: ВкусВилл имеет отдельный авто-поиск публичных
  **названий** без цен. Для остальных сетей ещё нет проверенного
  ценового адаптера; заявлять всеобщий автоматический парсинг
  **11/11 магазинов запрещено**.

## Независимые проверки

- Модульные Android-файлы `MagnitAutomaticPriceAdapterTest.kt`,
  `AutomaticRetailScanPolicyTest.kt`, `FoodPlanHomeScreenTest.kt`
  содержат реальные чтения **локальных test HTML** на Android,
  проверку `robots.txt`, 35 официальных URL, сценарий HTTP 403,
  10 яиц ≠ граммы, сохранение только корректной массы и отсутствие
  обязательной технической вкладки. Тестовые цены фиктивны и не
  должны попасть в production.
- [M4 live #40014617513](https://github.com/xxiamadelxx-blip/foodplan-ai/actions/runs/40014617513):
  **PASS проверка внешнего источника в GitHub runner**; 35/35
  свежих публичных цен фасовок, 29/33 доказанных стоимостей
  покупок **реальной недели**, известный подытог **6 995,40 ₽**,
  сумма всей недели UNKNOWN из-за 4 несопоставимых единиц:
  бананы с кожурой, нут в заливке, яйца, масло.
- [Android CI #40014617540](https://github.com/xxiamadelxx-blip/foodplan-ai/actions/runs/40014617540):
  **JVM и debug APK PASS**, проверка эмулятора **PENDING**
  на момент записи. Не считать Android-прогон принятым,
  пока нет завершённого лога.
- **Отдельный реальный сетевой запрос из Android-эмулятора
  к живой странице магазина пока не подтверждён**. Локальные
  тестовые страницы и отдельный live источник на GitHub runner
  доказывают разные части, не идентичные end-to-end проверке
  из пользовательского APK. Такой пробел обозначать явно.

## Приёмочные границы и продолжение

`M4 EMBEDDED AUTOMATION`: код IMPLEMENTED, полный Android
Gauntlet ещё не завершён. `M4 FULL WEEK PRICE`: PARTIAL,
**4 конверсии UNKNOWN**; не изобретать их. `M2` 0/150
независимых рецептурных проверок, `M3` питание частично,
`M5` физическое устройство unverified, `M6` настоящий
публичный подписанный выпуск BLOCKED.

Следующее независимое действие: прочитать результат эмулятора на
точном коммите; при PASS зафиксировать embedded parser в M4 как
отдельный субкритерий. Затем проверить **живой источник с телефона/
эмулятора**, не заменяя этот эксперимент успехом GitHub runner.
