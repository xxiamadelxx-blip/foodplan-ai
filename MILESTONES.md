## Критерии приёмки M2
1. Ровно 150 индивидуальных рецептов, не комбинаторные прототипы: **PASS**.
2. Оригинальный источник для каждого необходимого сырьевого нутриента:
   **PASS по reference 37/37**, не подтверждение готовой еды.
3. Независимый первичный источник технологии каждого блюда: **FAIL 0/150**.
4. Измеренный выход приготовленной партии для каждого блюда: **FAIL 0/150**.
5. Изученная маркировка ингредиентов/аллергенов конкретных продуктов:
   **FAIL**, не выводить безопасность из цены.
6. Независимые проверяющие и доказательная повторная проверка:
   **FAIL**, самолегитимизация CSV запрещена.

## Текущее рабочее решение и антизацикливание
- Проведена сверка: `docs/ROADMAP.md`,
  `docs/qa/M2_INDEPENDENT_RECIPE_REVIEW_PROTOCOL.md`,
  `tools/m2_review_intake.py`, экспорт `M2IndependentRecipeReviewExport`.
- Ни одно из этих доказательств не создаёт реальный замер блюда или
  независимого рецензента. Повторное самотестирование **не может**
  выполнить оставшиеся критерии, поэтому M2 фиксируется **BLOCKED**.
- Не запускать бесконечные повторы CI на неизменённом исходном коде M2 и
  не добавлять ради этого ещё 50/100/200 рецептных шаблонов.
- **Gauntlet M3, цикл завершён PASS на SHA `fe51d877`:** [Android CI #492](https://github.com/xxiamadelxx-blip/foodplan-ai/actions/runs/39815052231) подтвердил JVM-тесты, сборку APK, независимую повторную агрегацию Kotlin→Python (21 приём, 33 продукта) и эмулятор 43/43. Исходные CSV и независимый JSON сохранены как artifact `m3-actual-week-independent-evidence`. Это PASS конкретной задачи **экспорта**, не всего M3.
- **Gauntlet M4, новая независимая задача PARTIAL:** [настоящий публичный прогон #45](https://github.com/xxiamadelxx-blip/foodplan-ai/actions/runs/39815052032): 22/33 опубликованных цен; суммарный минимум известных покупок 362677 коп. (3 626,77 ₽). **11 UNKNOWN**, полная стоимость = UNKNOWN, бюджет 356 ₽ уже заведомо невозможен даже для известной части. 1 SKU `salmon` не прошёл проверку цены; источник не выдуман. Достоверность цен относится к сети, не к адресу/чеку.
- **Следующий проверяемый шаг M4:** получить точный перечень 11 отсутствующих ingredient IDs из artifact `m4-chain-price-public-evidence`; для каждого попробовать максимум три разрешённых независимых источника/карточки, фиксируя UNKNOWN при неуспехе. Затем сравнить полный недельный бюджет, не требуя точного адреса. Переходить к следующему ингредиенту при блокировке, без бесконечного рефакторинга.
- Повторять неизменённые пройденные тесты экспорта M3 **не нужно**, кроме обоснованной регрессии.
- **Следующий внешний шаг M2:** получить действительные внешние
  материалы экспертизы 150 рецептов, включая измеренный cooked yield.
  Без них статус остаётся BLOCKED, не PASS.
- **M4 без адреса:** по требованию пользователя считаются только
  приблизительные цены сети, без выбора доставки, точного магазина и
  кассового ценника. Никакие проверки адреса не блокируют M4.

## Протокол каждого последующего цикла
1. Читать этот файл, дорожную карту и последний проверенный SHA.
2. Выбрать ближайший **незакрытый проверяемый** пункт в утверждённом этапе.
3. Не раздувать scope; выполнять только недостающую реализацию.
4. Запустить подходящий тест, собрать независимые доказательства,
   исправить при FAIL, не более 3 попыток одной проблемы.
5. Обновить эту таблицу, дать ссылки на SHA/лог и оставшийся блокер.
6. При полном PASS сразу перейти к следующему M. При BLOCKED перейти
   к независимой задаче, сохранив этап открытым.
