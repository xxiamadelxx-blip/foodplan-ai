# FoodPlan AI · MILESTONES

Последняя ревизия: 22.10.2026. Источник истины по этапам и переходам.

**Ветка доказательств:** многие перечисленные функции реализованы в
[рабочем PR #3](https://github.com/xxiamadelxx-blip/foodplan-ai/pull/3)
и других указанных по ссылкам ветках; наличие подтверждённого CI
**не означает, что весь этот код уже попал в `main`**. Не путать
статус рабочей ветки со статусом пользовательского релиза.
**Режим работы:** выполнить ближайший критерий, Gauntlet Loop, PASS → сразу
дальше, BLOCKED после максимум трёх адресных попыток → другая независимая
задача, без ложного закрытия. Команда **«Продолжай»** исполняет этот алгоритм.

**Продуктовые решения всегда хранятся в [CONTEXT.md](CONTEXT.md).**
Развёрнутые пользовательские пострелизные задачи и критерии находятся в
[docs/POST_RELEASE_BACKLOG.md](docs/POST_RELEASE_BACKLOG.md). Новые требования
из чата сначала записывать туда и в UX-контракт, **не создавая новых M7/M8/M9**
и не выдавая запись плана за реализованное приложение.

## Критерии приёмки M2
1. Ровно 150 индивидуальных рецептов, не комбинаторные прототипы: **PASS**.
2. Оригинальный источник для каждого необходимого сырьевого нутриента:
   **PASS по reference 37/37**, не подтверждение готовой еды.
3. Независимый первичный источник технологии каждого блюда: **FAIL 0/150**.
4. Измеренный выход приготовленной партии для каждого блюда: **FAIL 0/150**.
5. Изученная маркировка ингредиентов/аллергенов конкретных продуктов:
   **FAIL**, не выводить безопасность из цены.
6. Независимые проверяющие и доказательная повторная проверка:
   **FAIL**, самолегитимизация CSV запрещена.

## Протокол каждого последующего цикла
1. Читать этот файл, дорожную карту и последний проверенный SHA.
2. Выбрать ближайший **незакрытый проверяемый** пункт в утверждённом этапе.
3. Не раздувать scope; выполнять только недостающую реализацию.
4. Запустить подходящий тест, собрать независимые доказательства,
   исправить при FAIL, не более 3 попыток одной проблемы.
5. Обновить эту таблицу, дать ссылки на SHA/лог и оставшийся блокер.
6. При полном PASS сразу перейти к следующему M. При BLOCKED перейти
   к независимой задаче, сохранив этап открытым.

## Цикл 2026-10-23 · M4 проверка штучной и объёмной фасовки

**Причина:** прежняя недельная проверка **31/33** знает цену и массу

съедобного яйца или физического масла. Старый pipeline отбрасывал их.

**Реализация в рабочем PR #3:** две реально существующие открытые
карточки Магнита стали кандидатами только для независимого
подтверждения **цен одной упаковки**:
- `egg` / 10 шт.:
  https://magnit.ru/product/3454700001-yaytso_stolovoe_s1_10sht_boks_20
- `oil` / 900 мл:
  https://magnit.ru/product/1000029331-maslo_podsolnechnoe_rafinirovannoe_dezodorirovannoe_900ml

Скрипт `tools/m4_live_chain_price_probe.py` различает
`pack_grams` и `pack_unit + pack_quantity`, проверяет название
и точное количество после `h1`, отбрасывает иные единицы. В
`tools/m4_actual_week_coverage.py` подтверждённая **цена одной
штучной/объёмной фасовки** может быть показана отдельно, но число
покупаемых пачек, расходы за неделю и бюджет по ней остаются
**UNKNOWN**, если производственный план содержит только съедобные
граммы. Ни граммы 10 яиц, ни плотность подсолнечного масла **не
додумываются**. Тесты требуют отбраковывать поддельный перевод.
